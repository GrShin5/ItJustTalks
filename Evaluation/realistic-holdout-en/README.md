# SEALED English realistic cleanup holdout

This set contains 60 fictional, synthetic English dictation cases. Run it once per frozen candidate; do not use it to tune prompts, rules, or models. Keep candidate development separate from this holdout.

The JSONL schema follows the Japanese realistic holdout. Each reference preserves spoken words and order, allowing punctuation, capitalization, pause-filler removal, cued retraction removal, and dictionary spelling. Open endings remain unfinished; short phrases do not receive a period. Tags overlap.

The set includes 10 cued corrections, 5 contrasts, 8 open endings, 12 filler cases, 8 cases with three dictionary entries, 22 cases with numbers, 10 rewording traps, 4 hands-free cases, and 3 short phrases. The other 57 transcripts are 80–400 characters.
