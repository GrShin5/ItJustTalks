# ItJustTalks 導入用プロンプト

配布元を確認し、下のコードブロック全体を、Macのローカルフォルダとコマンドを扱えるAIコーディングエージェントへ貼り付けてください。個人データの添付は不要です。作業を助けるエージェント自身の通信は、アプリのローカルAI処理とは別です。

```text
このMacへItJustTalks 0.1.0をソースからビルド・自己署名して新規導入してください。
取得元: https://github.com/GrShin5/ItJustTalks

守ること:
- 対象はItJustTalksだけです。AI処理はApple Foundation Modelsのオンデバイスモデルのみです。外部AIの導入・ログイン・APIキー設定は不要です。
- 利用者のデータを絶対にアップロードしないでください。発話、メール、選択本文、クリップボード、辞書、履歴、設定の本文を読取り・出力・外部送信しないでください。診断情報もアップロードせず、機密値は報告から除いてください。通信は指定ソースと必要な開発依存物の取得に限ります。
- セキュリティ設定は変更しないでください。Gatekeeper、SIP、権限データベース、キーチェーンの保護を緩めず、検証の無効化、ad-hoc署名、権限の一括リセットをしないでください。macOSの認証・許可操作はユーザー自身に任せてください。
- 署名証明書の新規作成が必要なら、ログインキーチェーンへの登録と署名の信頼設定が必要になることを説明し、実行前に必ずユーザーの承認を求めてください。その操作を希望しなければ停止してください。承認は他のセキュリティ設定の変更を許可するものではありません。
- Koedexのアプリ・リポジトリ・データに触れないでください。`~/Library/Application Support/Koedex*` は読取り・書込み・移行・削除・権限変更すべて禁止です。
- 変更済みソースや競合を見つけたら停止し、勝手に破棄・上書きしないでください。コミット、push、公開、不要なファイル削除はしないでください。
- エラー時はそこで止め、原因と必要な次の操作を説明してください。署名や識別子の不一致を迂回しないでください。アプリ起動や録音・文章入力の確認はユーザーに任せてください。

手順:
1. macOS 27であることを確認してください。AIにはApple Silicon、Apple Intelligenceの有効化、モデル準備、MacとSiriの言語の一致が必要です。Apple M5 Max（メモリ64GB）で確認。M1（メモリ8GB）は確認予定。Core 3搭載Macは未確認です。対応する開発ツールの正確な版は未確認で、Swift 6.4以上だけではSDK互換性を保証しません。
2. ユーザーが選んだ同期対象外のローカル作業フォルダで、取得元と保存先を確認してください。ソースはZIPダウンロードではなく git clone https://github.com/GrShin5/ItJustTalks で取得してください。Desktop・Documents・iCloud Drive・File Provider配下は使わず、例えば ~/Developer/ItJustTalks に配置してください。既存cloneならremote・ブランチ・git status --shortを確認し、違う取得元や未コミット変更なら停止してください。docs/manual/ja.mdの付録Bと対象スクリプトを読み、実行内容を確認してください。
3. bash scripts/preflight.sh を実行してください。preflightはmacOS 27以上を確認します。失敗を無視せず、証明書未作成だけが障害なら次の手順で扱ってください。開発ツールやOpenSSL 3の追加導入が必要なら内容を説明してユーザーに任せてください。
4. 有効な既存のItJustTalks署名を再利用してください。証明書がなければ上記の承認を得てから bash scripts/make_signing_cert.sh を実行し、ユーザーに認証画面の確認を任せてください。キーチェーン不達や未信頼は証明書不在と同一視しないでください。preflightを再実行し、問題が解消したことを確認してください。
5. bash scripts/make_app.sh release を実行し、bash scripts/verify_app_identity.sh dist/ItJustTalks.app で検証してください。
6. bash scripts/preflight.sh --install の成功後、bash scripts/install_app.sh を実行してください。既存のItJustTalks.appや同名項目がある場合は上書きせず、更新用プロンプトへ案内して停止してください。
7. 配置されたアプリを特定してverify_app_identity.shで検証し、ビルド版との一致を確認してください。作成物、配置場所、版、検証結果、未実施事項を短く報告してください。
8. ユーザーにFinderからの起動、マイク・音声認識・アクセシビリティの許可、Apple Intelligenceの状態確認、短い合成文でのキーと入力確認を案内してください。ビルド成功を実機合格と呼ばないでください。
```
